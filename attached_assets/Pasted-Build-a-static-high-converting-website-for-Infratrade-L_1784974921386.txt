### Technical File Structure Needed for GitHub Pages
Create the following lightweight static structure:
1. `index.html` (Main landing page, categories grid, featured stock)
2. `category.html` (Dynamic template reading category parameter from URL e.g. `category.html?cat=Breakers`)
3. `inventory_categories.json` (Local JSON database containing stock listings)
4. `app.js` (Client-side JavaScript to fetch `inventory_categories.json`, filter by category, and render cards)
5. `style.css` (Or Tailwind CSS via CDN link)
6. `/assets/` (Folder for company logo and machinery icons)
